# 법학과 블루북 시범 데이터 소스 맵

## 자료 개요

- 대상: 계명대학교 법학과 블루북
- 원본: `docs/reference/bluebooks/law/source.pdf`
- 구조화 파일: `src/data/bluebooks/law.json`
- 페이지 표기는 PDF 안쪽 하단에 인쇄된 쪽수다. PDF 뷰어의 물리 페이지와 다를 수 있다.
- 문서 발행연도·판본은 명확하지 않아 `sourceEdition`은 `null`이다.

## 사용 가능한 데이터

- 1~4학년 1·2학기 전공과목 표기와 전공필수 적용 안내
- 120학점 이상 이수 기준 및 전공영어/TOEIC 요건
- 편입학생, 외국대학과의 복수학위 이수학생, 외국인학생 예외
- 로스쿨/변호사시험, 법무사, 공인노무사, 공인중개사, 감정평가사, 변리사 및 공무원 진로의 원문 표기
- 진로 교육과정표의 학년별 과목 묶음과 화살표 흐름

## 사용하면 안 되는 방식

- 이 파일을 실제 2026-2학기 개설강좌, 수강 가능 여부, 강의시간 또는 분반 데이터로 사용하지 않는다.
- PDF에 없는 선수과목·대체과목·과목 관계를 추가하지 않는다.
- 화살표를 개별 법적 선수과목으로 해석하지 않는다.
- 현재 자격시험 요건·영어 기준·가산점을 확정 정보로 사용하지 않는다.
- 실제 DB의 `courses`, 학생, 수강·개설 데이터를 생성·수정하거나 자동 매칭하지 않는다.

## 진로 트랙 목록

- 로스쿨/변호사시험 (판사, 검사, 변호사)
- 법무사
- 공인노무사
- 공인중개사
- 감정평가사
- 변리사
- 검찰사무직/마약수사직 9급

- 철도공안직(철도경찰)·출입국 관리직·보호직·교정직 9급

## 명시된 관계와 해석된 관계

PDF의 화살표는 진로 표에서 학년별 과목 묶음을 잇는 표기다. JSON에서는 각 `courseSequenceByGrade` 항목에 `relationType: "recommended_sequence"` 및 `explicitlyStated: true`로 기록했다.

화살표가 한 과목에서 다른 과목으로 직접 연결된 것이 아니므로 `courseRelations`는 비워 두었다. PDF가 명시하지 않은 개별 `prerequisite` 관계는 해석하거나 생성하지 않는다.

## 실제 DB courses와 매칭할 때의 원칙

- 이 JSON의 `name`을 후보 문자열로만 사용한다.
- `departmentCode`, 현재 교육과정 연도, 실제 개설 상태, 과목 코드가 모두 확인된 경우에만 별도 검토 절차에서 매칭한다.
- 이름만 같은 과목은 자동 매칭하지 않는다.
- 매칭 결과는 블루북 원문 데이터와 분리해 보관하고, 원본 JSON을 변경하지 않는다.

## 발행연도 및 최신성

문서에 명확한 발행연도 또는 판본 표기가 없다. 졸업 요건의 적용 연도, 자격시험 과목·대체 기준·가산점은 변경될 수 있으므로 실제 안내 또는 시험 공고로 최신성을 별도 확인해야 한다.

향후 여러 학과 블루북을 추가할 때에도 동일한 JSON 구조를 사용한다. 원문에 없는 값은 추정하지 않고 `null`, 빈 배열 또는 `warnings`로 남긴다.
