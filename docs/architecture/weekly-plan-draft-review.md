# 2026-2 주간 계획 draft 검토

## 1. 회사법 주차 초안 요약

`회사법 강의계획서.pdf`의 parsed text에 직접 나타난 주제는 회사의 개념, 회사의 종류와 능력, 주식회사 설립, 주주의 지위, 주주총회, 이사와 이사회, 재무질서, 유한회사, 합병과 분할이다. 초안은 이 순서를 1~9주에 배치하고, 10~14주를 기존 주제의 복습·종합복습으로 표시했다. 15주는 평가 시점이 확인되지 않아 종합 복습으로만 두었다.

평가 비율은 출석 20%, 기말시험 30%, 중간고사 30%, 과제 20%로 확인되지만 시험·과제 주차는 확인되지 않았다.

## 2. 행정절차와행정구제 주차 초안 요약

`행정절차와행정구제 강의계획서.pdf`의 parsed text에 직접 나타난 주제는 행정절차법, 정보공개와 개인정보보호, 행정상 강제집행, 행정벌, 행정심판, 행정소송, 국가배상과 손실보상, 종합정리이다. 초안은 이 순서를 1~7주에 배치하고 8~13주를 주제별·종합 복습, 14주를 종합정리, 15주를 평가 시점 미상의 종합정리로 표시했다.

평가 비율은 출석 10%, 기말시험 50%, 중간고사 40%로 확인된다. 과제·발표·참고자료·수업목표는 parsed text에서 확인되지 않았다.

## 3. syllabus 원문에서 직접 확인된 항목

- 두 syllabus의 과목명, 강의시간, 강의실
- 회사법: 위 9개 법학 주제, 출석·중간고사·기말시험·과제 평가 비율
- 행정절차와행정구제: 위 8개 행정법 주제, 출석·중간고사·기말시험 평가 비율
- 두 syllabus의 `course_id`와 실제 offering의 과목 일치
- 두 offering의 `term_id`, 담당 교수, 2026-2 시간표는 DB read-only 확인 결과를 사용

## 4. 사람이 해석해 배치한 항목

- syllabus가 주차 번호를 제공하지 않으므로 2026-09-01을 1주차 시작 기준으로 순서를 배치
- 15주를 채우기 위한 10주차 이후 복습·종합복습 분배
- 주제 간 일반적인 개념→기관/절차→구제 순서
- 평가 주차를 확정하지 않고 review로 보류

위 항목은 모두 draft이며 실제 강의계획이나 법적 선수과목으로 해석하지 않는다.

## 5. 교수 확인이 필요한 항목

- 각 주제의 실제 주차와 강의 순서
- 중간고사·기말고사 주차
- 회사법 과제의 내용·제출 주차
- 결강·보강·휴일 반영 여부
- 주차별 학습목표, 참고자료, 복습 범위
- syllabus parsed text의 주제 목록이 전체 강의계획을 대표하는지 여부

## 6. 시험·과제 주차 불명확 사항

평가 비율은 확인되지만 중간고사·기말고사의 주차는 두 syllabus 모두 명시하지 않는다. 회사법은 과제 비율만 있고 과제 세부사항이 없다. 행정절차와행정구제는 과제·발표가 확인되지 않는다. 따라서 모든 draft week의 `isAssessment`는 false이며, 평가를 특정 주차에 배정하지 않았다.

## 7. 실제 DB 입력 전 승인 체크리스트

- [ ] 담당 교수가 두 JSON의 주차·주제 순서를 확인
- [ ] 중간고사·기말고사·과제 주차를 확인
- [ ] 주차별 학습목표와 참고자료를 확인
- [ ] `source_syllabus_id`와 offering FK를 재확인
- [ ] 1~15주 누락·중복·중복 topic을 확인
- [ ] `review_required=true`, `professor_confirmed=false` 정책을 확인
- [ ] 학생 식별정보가 content·guide·assignment에 포함되지 않았는지 확인
- [ ] 승인된 항목만 `course_weekly_plans`로 별도 입력 계획을 작성

## 8. 학생 노출 주의

교수 확인되지 않은 draft를 학생에게 주간 로드맵으로 노출하면 안 된다. 현재 student_courses의 offering 연결과 progress row도 없으므로 draft JSON은 저장소 검토 자료로만 취급한다.

## 9. 1-C-2A-2에서 DB 입력 가능한 조건

현재는 보류다. 다음 조건을 모두 충족한 뒤에만 별도 승인 단계에서 입력을 검토한다.

1. 교수가 주차별 주제와 평가 시점을 확인한다.
2. 1~15주 원문 근거와 학습목표·참고자료가 확정된다.
3. `source_syllabus_id`가 정확한 offering과 연결된다.
4. 학생 노출 정책과 `review_required`/`professor_confirmed` 상태가 합의된다.
5. 별도 단계에서만 DB insert 및 결과 검증을 수행한다.

이번 1-C-2A-1에서는 DB 변경, migration, seed 실행, 서비스 코드, UI, commit/push를 수행하지 않았다.
